# Creature assets

The first-cell scene is procedural and does not require external assets.
User-provided future assets can be placed in this folder and referenced from
the creature's `CREATURE_PRESENTATIONS` entry in `app.py`.

Recommended formats are GLB for animated 3D models (centered at the origin,
roughly 1.25 units tall, with embedded materials) or transparent 1024×1024
PNG/WebP for still images. Add only assets you have permission to use; files
in this folder are ignored by Git by default.
